# Poll App

A modern survey and voting application built with Angular, TypeScript, SCSS and Supabase.

## Features

- Create custom surveys
- Vote on active polls
- Live result updates
- Active / past survey separation
- “Ending soon” section for urgent polls
- Responsive desktop & mobile layout
- Form validation for required fields
- Dynamic poll results
- Supabase database integration

## Tech Stack

- Angular
- TypeScript
- SCSS
- Supabase
- Git & GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/edda14/poll-app.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
ng serve
```

Open:

```txt
http://localhost:4200
```
